Navigation approach
The list is the home surface

Alerts is the home page. Selecting a row opens the panel on the right, and the list stays where it was.

Leaving is always labeled

Open alert goes to the details. All alerts comes back. Never a silent jump.

Smaller screens contract

The navigation shrinks to icons when the panel opens. At 768 the panel covers the full width. See High-fidelity UI.

User flows for the 3 journeys
Prioritization
1Open Alerts2Read the four counts3Ask Harbor or open Filters4Read High-value assets · Critical first5Open an alert
Investigation
1Read the Summary2Check the Data lineage3Read Harbor's call and its reasoning4Open alert for the Details, Activity, Audit trail and Metadata tabs5Ask Harbor why6Set the verdict
Remediation and actions
1Read Harbor's call2Confirm, Restore link or Mark as expected3Restore link: edit the response or change the verdict4Mark as expected: answer Teach Harbor5Irreversible action: a named confirmation6Snooze or Add to incident if not now
Key interaction flows

Modify alert and Snooze sit under the title. Snooze starts at 5 hours and takes an optional note.

Bulk actions appear when rows are ticked. Harbor suggests the actions, or you tell it what to do in words.

Restore link asks whether to edit the response or change the verdict, instead of assuming a false positive.

Mark as expected opens Teach Harbor, which asks why and logs the reason.

Irreversible actions show a flag and a button that names the object, and only they ask for confirmation.
