Feature Definition

4 Nov 2026

Scope

Everything below was read off the screens and documentation collected for the Competitor Research Report, across all thirteen products: Matters.AI, Microsoft Purview DLP, Microsoft Defender XDR, Varonis, Netskope DSPM, Nightfall, CrowdStrike Falcon, Splunk Enterprise Security, SentinelOne, Cyera, Cyberhaven, BigID and Darktrace. An item is listed only if a screen or a vendor page showed it, and each row names the tools it was seen in. Nothing is added from memory. Where a tool is not named, the material did not show that item, which is not the same as the tool lacking it.

"Inside the alerts feature" means the alerts list, the alert or incident detail, and the actions and pivots reachable from them. Cyberhaven, BigID and Darktrace had no screens, so their rows rest on written documentation or marketing copy only.

Not established

  • Falcon, SentinelOne, Cyera, Cyberhaven, BigID: no disposition or close vocabulary was captured.

  • Cyera: no list view, no actions. Cyberhaven and BigID: no interface captured at all.

  • Darktrace: documented between 2020 and 2023; its current alerts interface is not established.

  • Netskope: what expanding a row reveals. Nightfall: the ellipsis menu's actions. Purview and Defender: default list columns.

  • Matters.AI: what Analyst Verdict values exist beyond Open and True Positive, whether a comment is required to change it, whether Mute has a duration, and roles and permissions.

  • Charlotte AI (Falcon) and Linea AI (Cyberhaven) interfaces: only in embedded video, so nothing is claimed about them.
